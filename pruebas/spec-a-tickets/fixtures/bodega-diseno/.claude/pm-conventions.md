# Convenciones de gestión

## Tracker

Sin tracker: archivos markdown en specs/<épica>/tickets/.

## Idioma

Español.

## Plantilla de issue

```markdown
## Contexto
<por qué existe este trabajo>

## Qué entrega
<el comportamiento que queda funcionando, visto por el usuario>

## Criterios de aceptación
- [ ] Dado <contexto>, cuando <acción>, entonces <resultado>.

## Fuera de alcance
<lo que este ticket no hace>

## Referencias
<spec, vista de diseño>
```

## Títulos

`BOD-<n>: <título en infinitivo>`, por ejemplo `BOD-12: Registrar ingreso de mercadería`.
