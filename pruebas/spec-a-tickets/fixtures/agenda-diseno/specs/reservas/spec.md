# Spec · Reservas

## Contexto

Agenda es una app para peluquerías. Queremos que los clientes reserven.

## Historias

### Reservar hora

Los clientes reservan una hora con un peluquero y reciben confirmación. También se puede cancelar, cambiar la hora, pagar por adelantado y dejar una reseña después.

## Reglas

- Por definir con el dueño: política de cancelación y si el pago adelantado es obligatorio.
